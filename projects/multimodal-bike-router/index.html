Multimodal Bike Router for First-/Last-Mile Transit Access

This project is a Python routing application for first-/last-mile transit access. It integrates OpenStreetMap, GTFS, and GIS bicycle-infrastructure data to produce routes that balance speed, safety, and detour tolerance.

  • Built a weighted graph-routing workflow with OSMnx and NetworkX.
  • Designed a configurable cost function that trades off travel time against bicycle safety and route directness.
  • Combined transit and bicycle-network data to study how routing choices shape multimodal accessibility.

The project connects directly to my research interests in routing problems, network optimization, and transportation tools that expose practical tradeoffs rather than only returning a single fastest path.
